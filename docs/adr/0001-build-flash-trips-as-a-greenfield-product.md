# Build Flash Trips as a greenfield product

Flash Trips is a new product, while Wanderlisted is a reference implementation and source of verified domain knowledge, scenarios, deterministic algorithms, provider lessons, evaluation datasets, and test ideas. Flash Trips will not preserve Wanderlisted's graph, runtime state, APIs, schemas, compatibility layers, or directory structure by default, because retaining those contracts would also retain the complexity the redesign is intended to remove.
